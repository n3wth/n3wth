The n3wth workspace ships three independent tools, each with its own package, release cycle, and audience. Pick the one that matches your task; you do not need to install them all.

<Columns cols={3}>
  <Card title="UI" href="/ui/quickstart">
    A React design system built on Astryx. Primitives, theme provider, page layout, and social image renderer.
  </Card>

  <Card title="Skills" href="/skills/quickstart">
    A catalog of Markdown instructions for coding agents. Inspect, install, and adapt agent workflows.
  </Card>

  <Card title="r3" href="/r3/quickstart">
    A local-first memory server for MCP clients. Embedded Redis and vector index, optional Mem0 cloud sync.
  </Card>
</Columns>

## What each one is for

**UI** is a React package published as [@n3wth/ui](https://www.npmjs.com/package/@n3wth/ui). Consume it as a dependency to get the shared Newth theme, component primitives, and page compositions across sites in and outside this workspace. Source lives in [packages/ui](https://github.com/n3wth/n3wth/tree/HEAD/packages/ui).

**Skills** is a catalog of agent-skill Markdown files with an install script, hosted at [skills.n3wth.com](https://skills.n3wth.com). Skills teach a coding agent one job. Install with a shell one-liner into `~/.gemini/skills` or `~/.claude/skills`. Source lives in [apps/skills](https://github.com/n3wth/n3wth/tree/HEAD/apps/skills).

**r3** is a standalone MCP server published as [@n3wth/r3](https://www.npmjs.com/package/@n3wth/r3). Point Claude Desktop, Claude Code, or Cursor at `npx @n3wth/r3` and it stores conversation memory in an embedded Redis plus a local vector index. Source lives in the separate [n3wth/r3](https://github.com/n3wth/r3) repository.

## Where to start

## Related projects

These repositories share a maintainer but ship separately from this workspace.

- [Lunch Money for Agents](https://github.com/n3wth/lunchmoney-mcp): a read-only financial MCP integration.
- [Canvas](https://github.com/n3wth/canvas): live canvases with realtime sync.
- [Markup](https://github.com/n3wth/markup): a prototype for agents collaborating with people in documents and chat.
