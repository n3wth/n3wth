r3 is a local-first memory server for MCP clients. It stores facts and
conversation context through tools over standard input and output. This page shows you how to connect r3 to your MCP client, write a memory, and read it back after a restart.

## How it works

Your MCP client launches r3 over stdio. r3 stores memory locally in three layers:

- **Embedded Redis** stores memory content and metadata via `redis-memory-server` (auto-downloaded binary, no external service). Falls back to an in-process store if it cannot start.
- **vectra** provides a local, file-backed vector index for semantic search with no network calls.
- **Mem0 cloud** is optional. Set `MEM0_API_KEY` to sync memories across machines. Without a key, nothing leaves your machine.

## Prerequisites

- Node.js 18 or later
- An MCP client (Claude Desktop, Claude Code, or Cursor)
- Network access for the initial npm install and Redis binary download
- A writable working directory for the vector index

## Connect r3 to your client

<Steps>
  <Step title="Add r3 to your MCP config">
    <Tabs>
      <Tab title="Claude Desktop">
        Edit `~/Library/Application Support/Claude/claude_desktop_config.json` on macOS (or the equivalent path on your OS):

        ```json
        {
          "mcpServers": {
            "r3": {
              "command": "npx",
              "args": ["@n3wth/r3"]
            }
          }
        }
        ```
      </Tab>
      <Tab title="Claude Code">
        Run this command in your terminal:

        ```bash
        claude mcp add r3 "npx @n3wth/r3"
        ```
      </Tab>
      <Tab title="Cursor">
        Add to `.cursor/mcp.json` in your project (or the global Cursor MCP config):

        ```json
        {
          "mcpServers": {
            "r3": {
              "command": "npx",
              "args": ["@n3wth/r3"]
            }
          }
        }
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step title="Restart and confirm tools">
    Restart or reconnect your MCP client after editing the configuration. Inspect the discovered tools: `add_memory`, `search_memory`, and `cache_stats` should appear. A successful MCP connection confirms transport readiness.
  </Step>
  <Step title="Write a memory">
    Ask the assistant to store a preference:

    ```text
    Remember that I prefer TypeScript and dark mode.
    ```

    The client calls `add_memory` with your message. You should see a confirmation like `Saved`.
  </Step>
  <Step title="Read it back in a new conversation">
    Start a new conversation and ask:

    ```text
    What are my preferences?
    ```

    The client calls `search_memory` and should return `You prefer TypeScript and dark mode.`
  </Step>
</Steps>

<Note>
  Some macOS installations need a newer GNU Make to build the embedded Redis dependency. If installation fails, see [Troubleshooting](/r3/troubleshooting).
</Note>
