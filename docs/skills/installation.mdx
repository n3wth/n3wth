The shell installer at [skills.n3wth.com/install.sh](https://skills.n3wth.com/install.sh) copies committed skill files from the [n3wth/n3wth](https://github.com/n3wth/n3wth) repository into your assistant's skills directory. It supports both flat files (`foo.md`) and folder skills (`bar/SKILL.md`).

## Install a single skill

Pass the target assistant and the skill ID:

```bash
curl -fsSL https://skills.n3wth.com/install.sh | bash -s -- gemini pdf
```

This downloads the `pdf` skill and copies it to `~/.gemini/skills/pdf.md`.

## Install all skills

Omit the skill ID to install the entire catalog:

```bash
curl -fsSL https://skills.n3wth.com/install.sh | bash -s -- gemini
```

## Install into a staging directory

Set the `SKILLS_INSTALL_HOME` environment variable to change where the `.gemini` directory is created:

```bash
SKILLS_INSTALL_HOME=/tmp/staging bash /tmp/install.sh gemini pdf
```

This copies the skill to `/tmp/staging/.gemini/skills/pdf.md` instead of your home directory.

## Folder skills vs flat skills

The installer handles two layouts:

| Layout | Source path | Destination |
| --- | --- | --- |
| Flat skill | `skills/<id>.md` | `~/.gemini/skills/<id>.md` |
| Folder skill | `skills/<id>/SKILL.md` | `~/.gemini/skills/<id>/` (copied as a directory) |

Folder skills are useful when a skill includes helper files alongside `SKILL.md`. Flat skills are simpler and sufficient for most instruction-only skills.

## Overwrite protection

The installer skips existing files by default. If a skill is already installed, you will see a warning and the file is left unchanged:

```text
gemini/pdf.md already exists, skipping
```

To force an update, remove the existing file first or use the experimental CLI with the `--force` flag.

## Available targets

| Target | Assistant | Skills directory |
| --- | --- | --- |
| `gemini` | Antigravity CLI | `~/.gemini/skills` |
| `all` | Equivalent to `gemini` | `~/.gemini/skills` |

Only `gemini` is supported today. Passing an unrecognized target prints `Supported target: gemini` and exits with an error.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Download refused">
    If the installer download fails, verify that curl is installed and that `skills.n3wth.com` is reachable. You can also clone the repository manually and copy files from [apps/skills/skills/](https://github.com/n3wth/n3wth/tree/HEAD/apps/skills/skills).
  </Accordion>

  <Accordion title="Target not recognized">
    The installer only accepts `gemini` and `all` as targets. If you pass another value, it exits with `Supported target: gemini`. Use `gemini` for Antigravity CLI.
  </Accordion>

  <Accordion title="Skill already installed">
    The installer skips files that already exist. Remove the existing file or directory under `~/.gemini/skills/` if you want to reinstall.
  </Accordion>
</AccordionGroup>
