`apps/skills/cli` contains an experimental Node CLI called `newth-skills` with its own catalog and download base. Most users should use the [shell installer](/skills/installation) instead.

## Status

The CLI manifest declares:

- **Name**: `newth-skills`
- **Version**: `1.0.0`
- **Bin**: `newth-skills` (points to `dist/index.js`)
- **Engine requirement**: Node `>=18.0.0`

The CLI catalog is a separate array in `cli/src/utils/skills.ts` and may diverge from the web catalog in `src/data/skills.ts`. Verify availability before relying on it; the package includes a `prepublishOnly` script but does not guarantee it is published to npm.

## Commands

The CLI exposes six top-level commands through `commander`:

| Command | Arguments | Options | Description |
| --- | --- | --- | --- |
| `list` |  | `-c, --category`, `-i, --installed`, `-f, --featured` | List available skills, optionally filtered |
| `search` | `<query>` |  | Search by name, description, or tags |
| `info` | `<skill-id>` |  | Show detailed information about a skill |
| `install` | `<skill-id>` | `-p, --platform <platform>`, `-f, --force` | Install a skill for the target platform |
| `uninstall` | `<skill-id>` |  | Remove an installed skill |
| `update` |  |  | Update all installed skills to their latest versions |

### Examples

```bash
# List all skills
newth-skills list

# List installed development skills
newth-skills list --category development --installed

# Search for PDF-related skills
newth-skills search pdf

# Install a skill
newth-skills install pdf

# Force reinstall
newth-skills install pdf --force

# Show details
newth-skills info pdf

# Remove a skill
newth-skills uninstall pdf

# Update everything
newth-skills update
```

## Differences from the shell installer

|  | Shell installer | `newth-skills` CLI |
| --- | --- | --- |
| **Catalog source** | `src/data/skills.ts` (web catalog) | `cli/src/utils/skills.ts` (CLI catalog) |
| **Install method** | Clones repo, copies files | Fetches raw files over HTTP or generates fallback content |
| **Platforms** | `gemini` (and `all`) | `gemini` only |
| **Overwrite behavior** | Skips existing files by default | Skips unless `--force` is passed |
| **Staging support** | `SKILLS_INSTALL_HOME` env var | Not supported |
| **Folder skills** | Copies full directories | Writes a single `.md` file |
| **Offline install** | Requires `git` and network | Requires network; generates fallback content if fetch fails |
| **State tracking** | None | Tracks installed versions in `~/.newth-skills/config.json` |

<Warning>
  If the CLI cannot fetch the remote skill file, it falls back to generating skill content from the catalog record (name, description, features, use cases, and sample prompts). This generated content is a best-effort substitute and may not match the full instruction file.
</Warning>
