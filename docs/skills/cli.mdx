<Warning>
  This CLI is experimental and maintains a separate catalog from the web installer. Most users should use the [shell installer](/skills/installation) instead.
</Warning>

The `newth-skills` CLI lives in [apps/skills/cli](https://github.com/n3wth/n3wth/tree/HEAD/apps/skills/cli). It ships its own catalog and download base, so available skills can drift from what you see at [skills.n3wth.com](https://skills.n3wth.com).

## Package details

| Field | Value |
| --- | --- |
| Name | `newth-skills` |
| Version | `1.0.0` |
| Bin | `newth-skills` → `dist/index.js` |
| Node | `>=18.0.0` |

The catalog lives in `cli/src/utils/skills.ts` and is maintained independently from the web catalog in `src/data/skills.ts`. Verify skill availability before depending on it. A `prepublishOnly` script is defined, but publication to npm is not guaranteed.

## Commands

Six top-level commands are exposed through `commander`:

| Command | Arguments | Options | Description |
| --- | --- | --- | --- |
| `list` |  | `-c, --category`, `-i, --installed`, `-f, --featured` | List available skills, optionally filtered |
| `search` | `<query>` |  | Search by name, description, or tags |
| `info` | `<skill-id>` |  | Show detailed information about a skill |
| `install` | `<skill-id>` | `-p, --platform <platform>`, `-f, --force` | Install a skill for the target platform |
| `uninstall` | `<skill-id>` |  | Remove an installed skill |
| `update` |  |  | Update all installed skills to their latest versions |

### Examples

```bash
# List all skills
newth-skills list

# List installed development skills
newth-skills list --category development --installed

# Search for PDF-related skills
newth-skills search pdf

# Install a skill
newth-skills install pdf

# Force reinstall
newth-skills install pdf --force

# Show details
newth-skills info pdf

# Remove a skill
newth-skills uninstall pdf

# Update everything
newth-skills update
```

## Differences from the shell installer

The two installers overlap in purpose but differ in almost every detail. Prefer the shell installer for anything user-facing.

<AccordionGroup>
  <Accordion title="Catalog source">
    **Shell installer** reads [apps/skills/src/data/skills.ts](https://github.com/n3wth/n3wth/blob/HEAD/apps/skills/src/data/skills.ts), the web catalog powering [skills.n3wth.com](https://skills.n3wth.com).

    **CLI** reads its own `cli/src/utils/skills.ts` array, which is maintained separately and can drift.
  </Accordion>

  <Accordion title="Install method">
    **Shell installer** clones the repository and copies files directly.

    **CLI** fetches raw files over HTTP. If a fetch fails, it falls back to generated content built from the catalog record.
  </Accordion>

  <Accordion title="Supported platforms">
    **Shell installer** targets `gemini` and `all`.

    **CLI** targets `gemini` only.
  </Accordion>

  <Accordion title="Overwrite behavior">
    **Shell installer** skips existing files by default.

    **CLI** also skips by default, but accepts `--force` to reinstall.
  </Accordion>

  <Accordion title="Staging directory">
    **Shell installer** honors the `SKILLS_INSTALL_HOME` environment variable.

    **CLI** does not support staging.
  </Accordion>

  <Accordion title="Folder skills">
    **Shell installer** copies full directories (`bar/SKILL.md` plus helpers).

    **CLI** writes a single `.md` file, so folder skills lose their helper assets.
  </Accordion>

  <Accordion title="Offline behavior">
    **Shell installer** requires `git` and network access.

    **CLI** requires network access, but falls back to generated content when a fetch fails.
  </Accordion>

  <Accordion title="State tracking">
    **Shell installer** does not track installed skills.

    **CLI** records installed versions in `~/.newth-skills/config.json`.
  </Accordion>
</AccordionGroup>

<Warning>
  When the CLI cannot fetch a remote skill file, it generates a best-effort substitute from the catalog record (name, description, features, use cases, and sample prompts). Generated content may not match the full instruction file.
</Warning>
