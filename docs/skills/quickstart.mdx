---
title: "Install your first skill"
sidebarTitle: "Quickstart"
description: "Inspect and install a skill for Antigravity CLI, then verify the instruction file on disk."
---

Skills are Markdown instructions for coding agents. Installing a skill copies instructions from the catalog into your assistant's skills directory so the agent can follow them during your sessions. It does not install the tools the instructions mention.

<Steps>
  <Step title="Check prerequisites">
    You need Bash, curl, Git, and Antigravity CLI. The installer target is `gemini`, which installs skills into `~/.gemini/skills`.
  </Step>
  <Step title="Browse the catalog">
    Visit [skills.n3wth.com](https://skills.n3wth.com) to browse available skills. The catalog is organized into categories: Development, Documents, Creative, Productivity, and Business.
  </Step>
  <Step title="Download the installer">
    Save the installer to inspect it before running it.

    ```bash
    curl -fsSL https://skills.n3wth.com/install.sh -o /tmp/install.sh
    ```

    <Warning>
      Open `/tmp/install.sh` in your editor before running it. The installer clones the public [n3wth/n3wth](https://github.com/n3wth/n3wth) repository and copies files into your assistant's skills directory.
    </Warning>
  </Step>
  <Step title="Install a skill">
    Run the installer with the target `gemini` and the skill ID you chose. For example, to install the `pdf` skill:

    ```bash
    bash /tmp/install.sh gemini pdf
    ```
  </Step>
  <Step title="Verify the installation">
    Confirm the file was copied into the skills directory:

    ```bash
    ls ~/.gemini/skills/pdf.md
    ```

    The command should print the file path. Open the file to inspect the instructions. This verifies the copy; whether the assistant uses the skill must be checked in an assistant session.

    If the installer reports that the file already exists, it has kept your existing copy. See [overwrite protection](/skills/installation#overwrite-protection).
  </Step>
</Steps>

<Note>
  `gemini` is the assistant ID used by the installer. Its display name is **Antigravity CLI** (formerly Gemini CLI). The installer copies files into `~/.gemini/skills`.
</Note>

<Note>
  The `skill-creator` skill also supplies a Claude Code recipe as an `extraInstallCommands` entry. It copies the file to `~/.claude/skills/skill-creator/SKILL.md`. There is no general `claude` installer target; most skills only support `gemini` today.
</Note>
