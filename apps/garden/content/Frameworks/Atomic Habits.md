Atomic Habits is a framework for building better habits, developed by James Clear to support [[Personal Development|personal development]] and behavior change.

## Components

- **Cue:** Make it obvious by using environmental design to trigger desired behaviors
- **Craving:** Make it attractive through [[Motivation Techniques|motivation techniques]] and reward systems
- **Response:** Make it easy by reducing friction and applying the Two-Minute Rule
- **Reward:** Make it satisfying with immediate positive reinforcement

## Usage

Used for personal habit development, helping individuals create lasting [[Behavior Change|behavior change]] through small, consistent actions.
