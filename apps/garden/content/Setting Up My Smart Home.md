# Setting Up My Smart Home

As of now, my smart home ecosystem consists of:

 **Core System**

- Home Assistant as the central hub (still deciding between Yellow or Green)
- Zigbee + Z-Wave dongles for device connectivity

 **Smart Lighting**

- Philips Hue ecosystem

 **Audio**

- Sonos speaker network

 **Surveillance**

- Synology Surveillance Station
- Scrypted integration for HomeKit compatibility
