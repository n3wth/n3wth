# Projects

Projects are how ideas become reality. They're the bridge between learning something and actually doing something with it.

## Project Philosophy

**Ship over perfect**: A completed project teaches more than an abandoned masterpiece.

**Document as you go**: Future you will thank present you for clear notes.

**Scope ruthlessly**: The graveyard of side projects is filled with "just one more feature" victims.

## Project Types

**Technical**
Building software, automation, tools. These scratch itches and build skills simultaneously.

**Creative**
Writing, design, media. Projects that express ideas and develop aesthetic sensibilities.

**Learning**
Courses, certifications, skill acquisition. Structured projects with clear endpoints.

**Physical**
Home improvement, maker projects, gardening. Tangible outcomes in the real world.

## Project Lifecycle

1. **Capture**: Note the idea when inspiration strikes
2. **Evaluate**: Does this deserve time? Does it align with goals?
3. **Scope**: Define minimum viable outcome
4. **Execute**: Do the work, document progress
5. **Ship**: Get it to "done" even if not perfect
6. **Reflect**: What worked? What would you do differently?
