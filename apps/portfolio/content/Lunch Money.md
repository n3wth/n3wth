[lunchmoney.sh](https://lunchmoney.sh) is an unofficial plugin for [Lunch Money](https://lunchmoney.app). It lets a coding agent look up spending, budgets, accounts, and recurring bills. Access is read-only: it cannot edit records or move money. It is not affiliated with Lunch Money.

Sign-in for the plugin is at [auth.n3wth.com](https://auth.n3wth.com), separate from a Lunch Money login. Source lives in [n3wth/lunchmoney-mcp](https://github.com/n3wth/lunchmoney-mcp). A separate list of Lunch Money developer resources is [n3wth/awesome-lunchmoney](https://github.com/n3wth/awesome-lunchmoney).
