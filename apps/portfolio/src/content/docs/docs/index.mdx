## Source and contributions

UI lives in the [n3wth workspace](https://github.com/n3wth/n3wth). The r3 runtime lives in [its own repository](https://github.com/n3wth/r3). To improve these docs, follow the [preview and publishing guide](/docs/publishing).

## Related projects

These repositories share a maintainer but ship separately from this workspace.

- [Lunch Money for Agents](https://github.com/n3wth/lunchmoney-mcp): a read-only financial MCP integration.
- [Canvas](https://github.com/n3wth/canvas): live canvases with realtime sync.
- [Markup](https://github.com/n3wth/markup): a prototype for agents collaborating with people in documents and chat.
