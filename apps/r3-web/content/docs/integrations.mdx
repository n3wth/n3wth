# Integration Guides

## Connect Gemini CLI

Add this entry to `.gemini/settings.json` in your project. Merge it with existing settings rather than replacing them.

```json
{
  "mcpServers": {
    "r3": {
      "command": "npx",
      "args": ["-y", "@n3wth/r3"]
    }
  }
}
```

Start Gemini CLI and run `/mcp` to inspect the server connection and available tools. Review tool calls before granting access to private data.

See the [Gemini CLI MCP documentation](https://geminicli.com/docs/tools/mcp-server/) for configuration and troubleshooting.
