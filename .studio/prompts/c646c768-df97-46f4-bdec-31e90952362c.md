branch — do NOT exit before reading the response:

  the user sent a follow-up. `message.text` is the new instruction,
  `edits` are newly-added style changes (append to the original edits),
  `newAttachments` are elements the user attached on this turn —
  **append them to your view of `attachments[]` before resolving any
  indices** in `message.attachments` or `edits[].attachment` (indices
  are into the combined list, starting at the length of the original
  `attachments[]`). `imageAttachments` are new absolute paths to Read.
  Continue working, post progress as usual, eventually POST `complete`

- `{"kind":"timeout"}` — the 5-minute window elapsed with no user
  action. Exit `done`; any later follow-up from the user will spawn a
  fresh subagent.

**Under no circumstances** exit before parsing the `complete` response.
Your work is not actually done until that curl returns and you act on

After your final POST, return ONLY the literal string `done`. Do not
